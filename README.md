# Big Data: Spark Analysis

Практическая работа по анализу больших данных с использованием Apache Spark.

## Задача
Обработка датасета интернет-магазина: анализ продаж по регионам, месяцам и категориям товаров.

## Стек
- Python 3
- PySpark
- Jupyter Notebook
- pandas, matplotlib

## Структура
- `analysis.ipynb` — основной ноутбук с анализом
- `data/sales.csv` — исходные данные
- `scripts/aggregate.py` — скрипт агрегации

## Задания
1. Загрузить данные из CSV
2. Очистить пропуски и дубликаты
3. Агрегировать продажи по регионам
4. Построить графики
5. Экспортировать результат
